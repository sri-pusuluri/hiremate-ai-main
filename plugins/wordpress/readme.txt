Embed real-time HireSort AI job openings, live applicant counts, and candidate screening directly on your WordPress site.

== Description ==

HireSort AI Careers allows any company using HireSort ATS to display dynamic, synchronized career listings on their WordPress website with zero code.

Features:
* Automatic synchronization with HireSort ATS
* Real-time applicant counts & early applicant highlights
* Auto-responsive height resizing without double scrollbars
* Dark mode and Light mode support
* Screening questions and custom candidate application forms

== Installation ==

1. Upload the `hiresort-careers` folder to `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to 'Settings' > 'HireSort Careers' and enter your Company Slug.
4. Add `[hiresort_jobs]` to any page or post.
