# Job Description: Full Stack Developer (React & Node.js)

## Role Overview
We are looking for a skilled Full Stack Developer to design, develop, and maintain responsive web applications. You will work on both customer-facing interfaces and backend APIs, ensuring high performance, scalability, and seamless user experiences.

## Responsibilities
- Develop responsive front-end user interfaces using React, TypeScript, and Tailwind CSS.
- Design, build, and maintain RESTful APIs and backend services using Node.js and Express.
- Work with relational databases (PostgreSQL) and implement efficient query structures.
- Integrate third-party services and payment gateways (e.g., Stripe, SendGrid).
- Write clean, maintainable, and well-tested code (Jest, React Testing Library).
- Collaborate with designers and product managers to translate mockups into fully functional products.

## Requirements
- 3+ years of experience in professional web development.
- Strong proficiency in JavaScript/TypeScript, React, and Node.js.
- Experience writing database schemas and SQL queries in PostgreSQL.
- Understanding of git workflow and CI/CD pipelines.
- Good communication and team collaboration skills.
