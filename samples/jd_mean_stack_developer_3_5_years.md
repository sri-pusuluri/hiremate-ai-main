# Job Description: MEAN Stack Developer (Angular & React) (3–5 Years Experience)

**Company:** Zool Technologies  
**Position:** MEAN Stack Developer (Angular, React, Node.js, MongoDB)  
**Experience Level:** 3–5 Years  
**Department:** Engineering & Development  
**Location:** Remote / Hybrid (Flexible)  
**Employment Type:** Full-Time  
**Salary Range:** Competitive (Based on technical assessment & experience)  

---

## About Zool
At **Zool**, we engineer enterprise-grade cloud applications, intelligent SaaS solutions, and resilient data-intensive web platforms. Our engineering team values clean modular architecture, solid type safety, robust API design, and automated continuous delivery. We are looking for an experienced, detail-oriented **MEAN Stack Developer (3–5 Years Experience)** proficient in **both Angular and React**, alongside **Node.js, Express, and MongoDB**, to develop mission-critical customer-facing and internal enterprise systems.

---

## Role Overview
As a MEAN / Full Stack Developer at Zool, you will play a pivotal role across the entire software development lifecycle—from architecting frontend single-page applications in Angular and React to building high-performance RESTful/GraphQL microservices in Node.js, managing scalable MongoDB document stores, and ensuring cloud-ready deployment. You will collaborate closely with UI/UX designers, backend architects, and DevOps engineers.

---

## Key Responsibilities

### 1. Frontend Application Engineering (Angular & React)
- Develop responsive, accessible, and high-performance Single Page Applications (SPAs) using **Angular (v14+)** and **React (v18+)** with **TypeScript**.
- Implement predictable state management architectures using **NgRx / RxJS Observables** (for Angular) and **Redux Toolkit / Zustand / React Query** (for React).
- Build modular, reusable UI component libraries styled with modern CSS frameworks (Tailwind CSS, Angular Material, Radix UI, Bootstrap).
- Optimize client-side bundle performance, lazy loading, code-splitting, and Core Web Vitals.

### 2. Backend & API Services Architecture (Node.js & Express)
- Design, build, test, and maintain robust, secure RESTful APIs and real-time WebSocket/GraphQL services using **Node.js** and **Express.js / NestJS**.
- Implement authentication and authorization workflows (JWT, OAuth2, RBAC, SSO, Session management).
- Write modular asynchronous middleware for request validation, error handling, rate limiting, and structured JSON logging.

### 3. Database Modeling & Optimization (MongoDB & Mongoose)
- Model complex document data schemas using **MongoDB** and **Mongoose ODM**.
- Design high-throughput indexing strategies, compound indexes, and aggregation pipelines for reporting and real-time analytics.
- Ensure data consistency, database migrations, connection pooling, and replication/sharding monitoring.

### 4. Quality Assurance, DevOps & Cloud Deployment
- Write automated unit and integration tests using **Jasmine / Karma / Jest** (Frontend) and **Mocha / Chai / Supertest** (Backend).
- Participate in Git-based feature branching workflows (Pull Requests, code reviews, semantic versioning).
- Work with containerization tooling (**Docker**) and CI/CD deployment pipelines (GitHub Actions, AWS/GCP, Linux VPS environments).

---

## Qualifications & Requirements

### Must-Haves (Required):
- **Experience:** 3 to 5 years of professional full-stack web development experience with the JavaScript/TypeScript ecosystem.
- **Frontend Dual-Competency:** Strong hands-on proficiency in **both Angular (Components, Services, Directives, RxJS, Dependency Injection) AND React (Functional Components, Hooks, Context API, Virtual DOM)**.
- **Backend Mastery:** Solid experience building scalable server-side applications with **Node.js** and **Express.js**.
- **Database Expertise:** In-depth knowledge of **MongoDB** schema design, aggregation pipelines, transactions, and Mongoose ODM.
- **TypeScript Proficiency:** Deep understanding of TypeScript (strict typing, generics, interfaces, union types) on both client and server.
- **API Standards:** Proven track record designing and consuming RESTful APIs, handling asynchronous I/O, and secure header management (CORS, Helmet).
- **Tooling & VCS:** Proficiency with Git, npm/yarn/pnpm, Postman, and webpack/Vite/Angular CLI.

### Nice-to-Haves (Bonus):
- Experience with **NestJS** or microservices architectures.
- Experience with relational databases (PostgreSQL / MySQL) alongside NoSQL.
- Familiarity with cloud platforms (AWS S3, EC2, Lambda, or Google Cloud).
- Experience with caching layers like Redis or message queues (RabbitMQ, Kafka).
- Knowledge of containerization with Docker and Kubernetes.
