## 🚀 How to Post These Jobs on Zool's ATS Portal

1. **Log in to HireSort AI** as a Zool Admin (or Super Admin switched to the **Zool** workspace).
2. Go to **Jobs & ATS** (`/jobs`) in the left navigation sidebar.
3. Click **"Post New Job"** / **"Create Requisition"**.
4. Fill in the fields using the metadata section provided at the bottom of each JD markdown file:
   - **Job Title:** (e.g. *UX/UI Designer*, *MEAN Stack Developer (Angular & React)*, *WordPress Developer*)
   - **Department:** *Product & Design* / *Engineering* / *Web Engineering*
   - **Location:** *Hybrid / Remote*
   - **Min/Max Experience:** *3 to 5 Years*
   - **Required Skills:** Enter comma-separated skills from the metadata table.
   - **Job Description:** Paste the complete markdown text from the corresponding file.
   - **Custom Screening Questions:** Add the 3–4 tailored screening questions provided at the bottom of each file.
5. Click **"Publish Job"**.
