## About Zool
At **Zool**, we craft high-performance digital brand hubs, bespoke enterprise web portals, and scalable e-commerce ecosystems. We believe WordPress, when engineered with clean object-oriented PHP, modern Gutenberg blocks, and headless architectures, is an unmatched digital publishing engine. We are seeking a passionate, detail-obsessed **WordPress Developer (3–5 Years Experience)** to lead the development and maintenance of enterprise-grade WordPress web applications.

---

## Role Overview
As a WordPress Developer at Zool, you will be responsible for building customized, lightning-fast, and secure WordPress sites from scratch. You won’t just be clicking page builders—you will build bespoke custom themes using modern Full Site Editing (FSE) and Gutenberg blocks, write tailored custom plugins to solve business challenges, integrate third-party REST APIs, optimize Core Web Vitals, and maintain enterprise security hardening.

---

## Key Responsibilities

### 1. Custom Theme & Gutenberg Block Development
- Develop lightweight, pixel-perfect, responsive WordPress themes from scratch using **PHP 8.x**, HTML5, semantic CSS/SCSS, and modern JavaScript (ES6+).
- Build custom **Gutenberg blocks** using React / `@wordpress/blocks` and **Advanced Custom Fields (ACF Pro / Flexible Content)**.
- Implement responsive design layouts based on Figma mockups without bloated multi-purpose themes or excessive third-party plugins.

### 2. Custom Plugin Engineering & Backend Integrations
- Architect and develop secure custom WordPress plugins adhering to WordPress VIP coding standards and object-oriented PHP principles.
- Hook into WordPress lifecycle actions and filters (`add_action`, `add_filter`) to extend native functionality.
- Integrate external services via the **WordPress REST API**, webhooks, payment gateways (Stripe, PayPal, Razorpay), CRMs (HubSpot, Salesforce), and marketing automation platforms.

### 3. WooCommerce & E-Commerce Customization
- Build and customize **WooCommerce** stores with custom checkout flows, dynamic product filtering, shipping hooks, and inventory synchronizations.
- Optimize database queries for high-volume catalogs and transactional databases.

### 4. Performance Optimization, Security & DevOps
- Optimize websites to achieve 90+ Google Lighthouse scores and pass **Core Web Vitals** (LCP, FID/INP, CLS).
- Implement server-side caching (Redis / Memcached / Varnish), CDN integration (Cloudflare), image optimization, and asset minification/bundling.
- Enforce rigorous WordPress security standards (input sanitization, data escaping, nonces, SQL injection prevention, rate limiting).
- Manage version control (Git), deployment pipelines, and staging-to-production database synchronization.

---

## Qualifications & Requirements

### Must-Haves (Required):
- **Experience:** 3 to 5 years of hands-on WordPress development experience in an agency, product company, or enterprise environment.
- **Core Languages:** Strong proficiency in **PHP (7.4 & 8.x)**, **MySQL**, **JavaScript (ES6+)**, **HTML5**, and **CSS3/SCSS**.
- **Custom Theme/Plugin Development:** Demonstrated capability of creating custom WordPress themes and plugins from the ground up without relying on heavy visual builders (Divi/Elementor).
- **ACF & Gutenberg:** Deep expertise with **Advanced Custom Fields (ACF Pro)**, Custom Post Types (CPT), Custom Taxonomies, and Gutenberg block creation.
- **WordPress Architecture:** Solid grasp of the WordPress template hierarchy, WP_Query, transient APIs, hook architecture, and REST API endpoints.
- **Security & Standards:** Firm adherence to WordPress Coding Standards (WPCS), nonces verification, and data sanitization (`sanitize_text_field`, `esc_html`, `$wpdb->prepare`).
- **Version Control:** Proficiency with Git workflows and deploying code to hosting environments (WP Engine, Kinsta, Cloudways, AWS, or DigitalOcean).

### Nice-to-Haves (Bonus):
- Experience with **Headless WordPress** using React, Next.js, or Vue.js frontends.
- Familiarity with build tools like Vite, Webpack, npm scripts, or Gulp.
- Experience with WooCommerce extensions and custom payment gateway development.
- Knowledge of multisite setups (WordPress Multisite / WPMS) and multi-lingual plugins (WPML, Polylang).
